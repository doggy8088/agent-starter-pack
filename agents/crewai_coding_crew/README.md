"# CrewAI 程式設計團隊代理\n\n這個代理結合了 CrewAI 的協作式 AI 能力與 LangGraph，提供一個互動式的程式設計助理，能夠透過對話理解需求並產生程式碼解決方案。\n\n## 架構\n\n這個代理使用 LangGraph 實作了一個對話式介面，與 CrewAI 開發團隊協調。其工作流程包括：\n\n1. 一個對話式代理，負責：\n   - 透過自然對話收集需求"
"   - 透過提出後續問題釐清模糊之處\n   - 將實際的程式設計工作委派給 CrewAI 開發團隊\n\n2. 一個 CrewAI 開發團隊，由以下成員組成：\n   - 資深工程師：負責實作程式碼解決方案\n   - 首席品保工程師：評估並驗證已實作的程式碼\n\n## 主要特色\n\n- **互動式需求收集**：使用 LangGraph 維持自然的對話流程，同時收集並釐清程式設計需求"
"- **協作式 AI 開發**：利用 CrewAI 的多代理系統將工作分配給專業的 AI 代理\n- **順序處理**：任務依序處理，從需求收集到實作再到品質保證\n\n## 運作方式\n\n1. LangGraph 工作流程管理對話狀態，並決定何時：\n   - 繼續對話以收集更多需求\n   - 將工作委派給 CrewAI 開發團隊\n   - 將結果返回給用戶\n"
"2. 當需要程式設計時，CrewAI 團隊會透過一個自訂工具啟動，該工具：\n   - 將需求傳遞給資深工程師代理\n   - 將實作路由給品保工程師進行驗證\n   - 返回最終、經過驗證的解決方案\n"
