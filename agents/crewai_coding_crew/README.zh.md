# CrewAI 程式設計團隊代理

此代理結合 CrewAI 的協作式 AI 能力與 LangGraph，以提供互動式程式設計助手，該助手能透過對話理解需求並產生程式碼解決方案。

## 架構

此代理實作了一個使用 LangGraph 的對話式介面，該介面與 CrewAI 開發團隊協調運作。其工作流程包含：

1. 一個對話式代理，它會：
   - 透過自然對話收集需求
- 透過追問來釐清模糊之處
   - 將實際的程式設計工作委託給 CrewAI 開發團隊

2. 一個 CrewAI 開發團隊，包含：
   - 資深工程師：負責實作程式碼解決方案
   - 首席品管工程師：評估並驗證實作的程式碼

## 主要功能

- **互動式需求收集**：利用 LangGraph 維持自然的對話流程，同時收集並釐清程式設計需求
- **協作式 AI 開發**：利用 CrewAI 的多代理系統將工作分配給專業的 AI 代理
- **順序處理**：任務依序處理，從需求收集到實作再到品質保證

## 運作方式

1. LangGraph 工作流程管理對話狀態並決定何時：
   - 繼續對話以收集更多需求
   - 將工作委託給 CrewAI 開發團隊
   - 將結果返回給使用者
2. 當需要程式設計時，CrewAI 團隊會透過一個自訂工具啟動，該工具會：
   - 將需求傳遞給資深工程師代理
   - 將實作導向給品管工程師進行驗證
   - 返回最終且已驗證的解決方案
